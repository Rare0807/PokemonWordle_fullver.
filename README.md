# PokemonWordle_fullver.
大学3年のころに学祭で作ったプログラムです。当時の説明文を下記に貼り付けます。

ポケモンWordle(全ポケモン版)

①ゲームの目的
すべてのポケモンの中からランダムで一匹ポケモンが選ばれるので、
文字の一致具合からそのポケモンの名前を推測します。

②ルール説明
1. ゲームを開始すると自動で、答えとなるポケモンが選ばれます。
   答えのポケモンの文字数が画面上部に表示されます。
2. 入力バーにポケモンの名前を入れ「入力」のボタンを押すと、
   答えのポケモンとの文字の一致具合が画面下部に表示されていきます。
   ◯…文字も位置も一致
   △…文字は一致しているが、位置が違う
   ×…文字が不一致
3. 2.の工程を繰り返して答のポケモンにたどり着くと、ゲームクリアです。
4. ギブアップしたい場合は、入力バーに「ギブアップ」と入力しボタンを押してください。
   答えのポケモンが表示され、ゲームが終了します。
5. もう一度ゲームをプレイしたい場合は、「リトライ」のボタンを押してください。
   答えのポケモンが再抽選され、もう一度遊ぶことができます。

③本家「ポケモンWordle」との違い
・5文字でないポケモンにも対応
・解答数制限なし
・モードは一種類のみ
・△の仕様に違いあり
(答えがピカチュウのとき、シュシュプを入力すると「×△×◯×」と表示される)
